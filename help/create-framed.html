Content

Multiple create mod building block sets have received dyed variants!

  • Framed Glass
  • Framed Glass Panes
  • Horizontal Framed Glass
  • Horizontal Framed Glass Panes
  • Vertical Framed Glass
  • Vertical Framed Glass Panes
  • Tiled Glass
  • Tiled Glass Panes
  • Framed Glass Doors
  • Framed Glass Trapdoors
  • Cardboard
  • Bound Cardboard

Additionally, some other miscellaneous decorative blocks have been added, such as more window/window pane variants.

  • Zinc Window
  • Copper Window
  • Brass
  • Rose Quartz
  • Andesite
  • Cardboard (Peephole)
    • w/ Dyed variants

Obtaining

You can obtain the dyed variants of (most) blocks by the same method as vanilla glass blocks - taking the base, uncoloured block and surrounding a piece of dye with it within a crafting grid. The same goes for cardboard block variants.

Additional window variants are created in a similar fashion to base Create mod windows, by taking 3 of the respective material and collapsing them onto a glass block within a crafting grid.

Compatibility

Create: Framed hosts compatibility on accessible versions for Alex's Caves' Radon Lamps with Framed Radon Lamps.

Note: Alex's Caves is currently only supported on 1.20.1 as of writing, so this is a 1.20.1 exclusive feature. However, you can still technically access these blocks through commands.

Easter Eggs

Deploying any item tagged as "minecraft:fishes" (salmon, cod, pufferfish, etc.) onto a regular Block of Cardboard will give you a Block of Karpboard, referencing Magikarp from the popular franchise Pokémon.

Additionally, deploying a Gold Block onto a Block of Karpboard will provide a Shiny Block of Karpboard.

There are 19 rare package styles added, 16 of which are coloured variants while the other 3 are proper easter egg features.

Note: For those unaware, packages from the Create mod can occasionally spawn with a rare, easter egg texture. The 19 implemented by this mod act the exact same way with the same chance as the "vanilla" textures.
