Obtaining

The Mechanical Insolator can be created by combining Dirt (item tagged as #minecraft:dirt), Copper Casing, and a Mechanical Pump within a crafting grid.Figure II An extended list of items tagged as (minecraft:dirt) can be found below:

  • Dirt (minecraft)
  • Grass Block (minecraft)
  • Podzol (minecraft)
  • Coarse Dirt (minecraft)
  • Mycelium (minecraft)
  • Rooted Dirt (minecraft)
  • Moss Block (minecraft)
  • Mud (minecraft)
  • Muddy Mangrove Roots (minecraft)

Functionality

The Mechanical Composter creates a key item for automating many of the various plants that are able to be automated within Create: Mechanical Botany. This key item is Compost, which can be drained by an Item Drain from the Create mod to create Liquid Compost.

Compost, in item form, can be crafted into Tree Fertilizer, an item introduced by base Create mod. You can also press it for a chance to create a piece of Bone Meal.

Compacting this item into a Block of Compost will allow you to wash it into Mud or haunt it into Dirt. Additionally, you can also spout some Water onto it in order to produce Podzol.

Configuration

The Mechanical Insolator can be affected by 5 configuration options, all being handled through the server, meaning you cannot adjust these settings as a player on a server. However, if you are a server owner, moderator, or are playing in singleplayer, these configs can be changed regardless.

Kinetic Stress Impact | Default: 64 | Range: > 2

Determines the kinetic stress impact value of the machine. What this value means is that if you are running your machines at 256 RPM and this value is equal to 2, then it will consume 512 stress units.

Processing Time Multiplier | Default: 1 | Range: > 1

Determines the multiplier applied to the duration of processing recipes within the Mechanical Insolator. If this value is kept at 1, all processing times will be their default values. However, if increased to, for example, a value of 4, then all processing times will be multiplied by 4. (The Allium processing recipe is 20 seconds by default, so in this example it'd now become 80 seconds instead)

Compatibility

The Mechanical Insolator has built-in support for various mods, including but may not be limited to:

  • Ars Elemental
  • Ars Nouveau
  • Biomes O' Plenty
  • Create: Bitterballen
  • Create: Cafe
  • Create: Garnished
  • Create: Garnished Reworked
  • Farmer's Delight
  • Floralis
  • Hibernal Herbs
  • Oh The Biomes We've Gone
  • Supplementaries
  • Twilight Forest
  • Vanilla Backport

Note: The mods present in the list above may not include all vegetal content from them, but limited sections. For example, the Twilight Forest compat implemented into the Mechanical Insolator is limited to just tree automation.

Brief History

Within the same update that implemented the Blocks of Compost and reworked how Compost works in various ways, the texture utilised for the inner section was changed to reflect this new block.
