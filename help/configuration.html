Basics

While configs can be a bit complicated at times, for the purposes of my mods, configs are split into 3 categories - CLIENT, COMMON, and SERVER. Each of these act differently than the others and serve their own unique purpose, being utilised in different aspects of Minecraft's code and, by proxy, my mods. Technically speaking there's also STARTUP, but I'm not going to be covering that here as I don't believe I use STARTUP configs anywhere, though this may change in the future.I

As a general rule of thumb for this page, whenever I need to refer to something outside of my knowledge, it'll be from the Neoforged Documentation on the subject unless I find it necessary to utilise another source.

Client Configurations

These types of configuration options can be configured by the player no matter if they are a server admin or not, controlling stuff on the client-side of things.

This can include, for example, whether or not emitted particles are visible to you or the density of fog/vision obscurity while within fluids. A mod that utilises the latter function is the Create mod through the Fluid Fog Settings, which determines how far in front of the player can be seen.

Common Configurations

These types of configuration options can be configured by both the player and server owners/moderators. The main caveat of common configuration options is that in order to join a server, the client's value for the option must match the server's value for the option. If these values are different, the player cannot join the server.
